# Batch and queue workflow

Type: task
Status: resolved
Blocked by: 02, 03, 05

## Question

How should Galaxy execute, inspect, retry, cancel, and resume a batch of
single-voice, multilingual, or long-form synthesis items without overrunning
available CPU/GPU resources?

## Done when

The Batch contract covers JSONL/import, per-item overrides, combined output,
progress, partial success, retry, and a portable batch manifest.

## Answer

- Batch accepts plain line input, paragraph-based long-form input, and JSONL.
  JSONL items may override ID, language, speed, duration, voice/profile,
  instruction, and output formats before execution.
- A persistent `BatchRun` owns ordered item states, attempts, errors, artifact
  references, task identity, progress totals, warnings, and combined outputs.
  Successful items are never regenerated by resume or failed-item retry.
- Galaxy schedules one Batch task through the shared named-resource scheduler.
  Items execute sequentially through the engine-neutral Studio adapter so GPU
  memory is bounded and another engine can replace OmniVoice at the adapter
  boundary.
- Pause is cooperative between items. Cancel stops the active engine worker and
  leaves unfinished items pending. Interrupted or cancelled runs can resume;
  partial runs can retry only failed items.
- An item failure is recorded and does not discard prior or later successes.
  The run finishes as `completed`, `partial`, or `failed` from item outcomes.
- Combined WAV/MP3 is built from successful items in source order with a
  configurable gap. A combine failure is a warning and preserves item outputs.
- Each item is checkpointed atomically. The local sidecar contains machine
  paths needed for resume, while `batch.manifest.json` uses relative artifact
  paths, excludes credentials and output-root paths, and remains portable.
- The native Batch surface supports file import, parsing into an editable item
  table, per-item overrides, live controls, per-item playback, combined export,
  manifest download, history, resume, and retry.
